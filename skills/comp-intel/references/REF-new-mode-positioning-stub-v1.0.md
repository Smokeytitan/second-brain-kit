## 0. How to Use This File

Use this file during the new mode's Step 4a gap analysis.

- **STRONG** — you have a specific, already-approved counter without a draft tag
- **WEAK** — a counter exists but is marked `[DRAFT — NEEDS REVIEW]`
- **MISSING** — no usable counter exists yet; file a battlecard gap

When your active materials do not provide a validated counter, prefer a draft marker over
inventing a polished response.

Cross-references:
- Mode registry: the registry (or stub) file for this mode

## 1. Your Claims Usable As Draft Inputs

These are safe seed themes for the new mode. They are not polished messaging claims unless
explicitly approved elsewhere. Typical safe seed themes:

- `[DRAFT — NEEDS REVIEW]` You have an established footprint and operating surface, unlike
  newly seeded competitors that are only now being added to the registry.
- `[DRAFT — NEEDS REVIEW]` You can answer selection pressure with a broader product story
  than a single-category claim, because your stack spans multiple product lines.
- `[DRAFT — NEEDS REVIEW]` Frame relevance through existing ecosystem depth and operational
  maturity rather than chasing single-feature claims.
