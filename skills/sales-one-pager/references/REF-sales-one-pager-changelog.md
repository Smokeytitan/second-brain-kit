# Sales One-Pager — Changelog

---

## v1.2

**Template structural updates (Variant A).**

- Added **Section 2 — Product Definition**: `**What is [Product Name]?**` on its own line followed by a plain-language definition, 154 characters max (hard cap).
- Restructured **Section 3 — Audience** into two parts: (a) the existing 40-word audience summary, and (b) a new list of use-case lines in the format `USE_CASE_NAME - outcome`, 68 characters max per line. Uses hyphen separator, never em dash.
- Renamed **Section 5** to **How It Works / What You Get** with a resolution rule: "How it works" for single-feature/capability products where blocks describe mechanics; "What you get" for bundled/stack products where blocks describe deliverable components. Default to "How it works" when ambiguous.
- Renumbered sections 6–10 accordingly.

---

## v1.1

**Reviewer rescope + gate change.**

- REF reviewer: rescoped from B2B SaaS PLG (lead-gen) to enterprise BD collateral. Replaced SaaS-specific criteria (lead magnets, "Book 15-min discovery" CTAs, email-send optimization, sandbox mention) with BD CTA fitness, evidence anchors, and template rule conformance.
- REF reviewer: added Voice & tone criterion anchored to the company brand-voice guide, with severity parity to structural/evidence checks.
- RUN Step 3.5: removed auto-rewrite behavior. No verdict (Red/Yellow/Green) triggers silent edits. Review findings surface to the user alongside the unmodified Step 3 draft.
- RUN Step 4: updated output header to show verdict + must-fix list; removed "Fixed before sending" line.
