# GTM Campaign Template

A proven product-launch GTM framework. Use this structure for every product launch.

## Template Structure

### 1. Marketing Overview Table
Create a summary table with:
- Product name
- One-line summary
- Target audience
- Marketing DRIs (who owns what)
- Project tracker link
- Target launch date
- Important links (PRD, design, staging)

### 2. Market Opportunity
- **Problem:** What's broken today? Why does the status quo fail?
- **Opportunity:** What does this product change? Size the opportunity with data.

### 3. Positioning
- **Market landscape table:** Map competitor approaches (3-5 categories)
- **Core differentiator:** One clear reason this wins
- **Competitive moat:** 2-3 interlocking advantages
- **Leverage points:** Why each advantage compounds over time

### 4. Audience Segmentation
For each audience create a row with:
| Audience | What they care about | Tailored message | Proof points |
Include pain points for each audience.

### 5. Messaging
- **Overarching narrative:** One sentence that works everywhere
- **Sub-product positioning:** How features/components relate to each other
- **Value props per audience:** Specific benefits framed for each segment

### 6. Competitive Comparison
Feature-by-feature table:
| Feature | Our Product | Competitor A | Competitor B |

### 8. Social Campaign
- **Launch posts:** Main announcement thread (X), QT from {COMPANY_HANDLE}, LinkedIn, community channels
- **Founder/exec threads:** {FOUNDER}, {CEO}, other leaders
- **Employee advocacy:** Push through the employee advocacy program if you have one
- **Creator program:** Content briefs for community creators if you run a program
- **Follow-on drip:** 2-4 weeks post-launch, value prop posts

### 9. Blog Post
Structure:
- tl;dr (4-5 bullet points)
- Problem statement
- Solution overview
- How it works (technical but accessible)
- Sector-specific use cases (if applicable)
- CTA
