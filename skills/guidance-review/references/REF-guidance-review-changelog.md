# Guidance Review — Changelog

## v1.0.0

- Initial skill creation
- Added `product-legal` as first guidance document (example: legal compliance for a
  product combining regulated and unregulated components)
  - 22 rules across 6 categories: Entity & Regulatory Claims, Approved Language,
    Prohibited Language, Required Disclaimers, Security & Certification Claims,
    Slides & BD Guidelines
- Workflow: 6-step review (accept input → resolve guides → segment content →
  rule-by-rule review → disclaimer check → assemble output)
- Output format: checklist summary + inline annotations
- Guide registry with convention-based discovery + keyword alias support
